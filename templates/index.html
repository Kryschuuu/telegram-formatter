Hilfe & FAQ

Wie verknüpfe ich einen Kanal?

  1. Öffne deinen Telegram Kanal oder deine Gruppe.
  2. Gehe in die Einstellungen -> Administratoren.
  3. Füge @{{ bot_username }} als Admin hinzu (Recht: "Nachrichten senden" ist zwingend erforderlich).
  4. Kopiere die ID des Kanals (z.B. aus der URL im Telegram Web Client, meist beginnend mit -100).
  5. Füge sie im Tab "Meine Kanäle" hinzu.

Wie formatiere ich meinen Text?

Wir nutzen ein einfaches Markdown-System, das direkt für Telegram optimiert wird:

  • # Überschrift wird zu 🚀 Überschrift
  • ## Untertitel wird zu 📍 Untertitel
  • **Fetter Text** wird zu Fetter Text
  • *Kursiver Text* wird zu Kursiver Text
  • Link-Buttons können bequem über das Formular unterhalb des Textes hinzugefügt werden.
