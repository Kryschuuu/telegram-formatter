📖 Anleitung: So funktioniert's!

Willkommen beim Telegram Post Master! Damit das Tool deine Texte formatiert an dich senden kann, sind zwei kleine, einmalige Schritte nötig.

Wichtig: Aus Datenschutzgründen sendet das Tool Nachrichten immer nur an die Chat-ID, die links in der Seitenleiste eingetragen ist. So ist sichergestellt, dass deine Entwürfe privat bleiben!

Schritt 1: Den Bot aktivieren

Telegram erlaubt es Bots nicht, Nutzer von sich aus anzuschreiben. Du musst den Bot zuerst aktivieren.

  • Öffne deine Telegram App.
  • Suche nach unserem Bot (Tipp: Füge hier deinen @BotNamen ein).
  • Klicke unten auf den Button START.

Schritt 2: Deine Chat-ID herausfinden

Der Bot benötigt deine eindeutige Nutzer-Nummer (Chat-ID), um dich zu adressieren.

  • Suche in Telegram nach dem offiziellen Bot @userinfobot (oder @getmyid_bot).
  • Klicke bei diesem Bot auf Start.
  • Er antwortet dir sofort mit deiner ID (z.B. Id: 123456789).
  • Kopiere diese lange Zahl.

Schritt 3: Chat-ID eintragen & Senden

Füge die kopierte Zahl auf dieser Webseite links im Menü in das Feld "Deine Chat-ID" ein. Dein Browser speichert diese Nummer automatisch für deinen nächsten Besuch ab.

Gehe nun in den Editor, schreibe deinen Text und klicke auf "Direkt Senden"!

Tipps zur Formatierung

  • # Haupt-Überschrift → Wird groß, fett und bekommt eine 🚀
  • ## Untertitel → Wird fett und bekommt einen 📍
  • **Wichtig** → Wird fett dargestellt
  • - Punkt 1 → Wird in Aufzählungspunkte • umgewandelt
