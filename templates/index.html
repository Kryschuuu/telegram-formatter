So funktioniert's — Schritt für Schritt

  1. 1

    Bot-Token holen

    In Telegram @BotFather anschreiben, /newbot ausführen und den angezeigten Token kopieren. Ihn als Umgebungsvariable TELEGRAM_BOT_TOKEN setzen (oder beim Deployen im Hosting-Panel eintragen).

  2. 2

    Chat-ID ermitteln

    @userinfobot anschreiben und die eigene numerische ID ablesen; für Gruppen/Kanälen den Bot dort hinzufügen und die (negative) ID via getUpdates auslesen. Als TELEGRAM_CHAT_ID setzen.

  3. 3

    Text eingeben

    Markdown mit Formatierungen (Fett, Kursiv, Code, …), LaTeX-Formeln ($…$ / $$…$$) und Tabellen links in den Editor schreiben.

  4. 4

    Vorschau & Payloads prüfen

    Rechts erscheint sofort die Live-Vorschau und darunter die exakt gebauten Telegram-API-Payloads — inklusive automatischer Aufteilung in mehrere Nachrichten, falls nötig.

  5. 5

    Senden

    Auf „An Telegram senden" klicken — der Status unter dem Button zeigt Erfolg oder Fehlermeldung. Mit „Zurücksetzen" lässt sich alles wieder leeren.

FAQ — Häufige Fragen

Ist der Bot-Token sicher? Wo wird er gespeichert?

Der Token liegt nur als Umgebungsvariable auf dem Server und wird ausschließlich für den Versand an die Telegram-API verwendet — er wird nie im Browser ausgeliefert, nicht in Logs geschrieben und nicht in einer Datenbank gespeichert. Behandele ihn dennoch wie ein Passwort: nie öffentlich posten, bei Verdacht via @BotFather mit /revoke neu erzeugen.

Wie finde ich meine Chat-ID heraus?

Für Privat-Chats: @userinfobot starten und die angezeigte Zahl verwenden. Für Gruppen und Kanäle den Bot hinzufügen, eine Testnachricht senden und die chat.id im Antwort-JSON von https://api.telegram.org/bot<TOKEN>/getUpdates ablesen (Gruppen-IDs beginnen meist mit -100).

Warum sieht meine LaTeX-Formel in der Vorschau einfach aus?

Die Editor-Vorschau ist nur eine Orientierung. Echtes LaTeX-Rendering passiert erst in Telegram selbst: Sobald $…$-Formeln oder Tabellen erkannt werden, baut das Tool automatisch eine Rich-Message, die Telegram nativ als Formel rendert (Bot API 10.1+). Die Vorschau kann das browserseitig nicht leisten — der Payload rechts zeigt dir aber das korrekte Ergebnis.

Wie lang darf eine Nachricht sein?

Telegram erlaubt 4096 Zeichen für klassische und 32768 Zeichen für Rich Messages. Längere Texte werden automatisch an Absatz-, Zeilen- und Wortgrenzen aufgeteilt — ohne Formatierungen oder Tabellen zu zerreißen. Die Statuszeile unter dem Sende-Button zeigt an, wenn in mehrere Nachrichten aufgeteilt wurde.

Was passiert mit meinen eingegebenen Daten?

Nichts Bleibendes: Deine Eingaben werden nur im Arbeitsspeicher konvertiert und — nur wenn du aktiv auf „Senden" klickst — an die Telegram-API übergeben. Es gibt keine Datenbank, keine Analyse-Cookies, kein Tracking und keine Auswertung. Beim reinen Konvertieren ohne Sende-Button verlässt dein Text den Server gar nicht Richtung Telegram.

Welche Formatierungen werden unterstützt?

Fett **x**, Kursiv *x*/_x_, Unterstrichen __x__, Durchgestrichen ~~x~~, Inline-Code `x`, Codeblöcke, Links, Überschriften, Listen und Blockquotes — zusätzlich LaTeX-Formeln und Pipe-Tabellen (als Rich Messages).

Es klappt nicht — was kann ich bei Fehlern tun?
  • „TELEGRAM_BOT_TOKEN nicht konfiguriert" → Umgebungsvariable setzen und den Server neu starten.
  • „Keine Chat-ID angegeben" → TELEGRAM_CHAT_ID setzen (Howto, Schritt 2).
  • „401 Unauthorized" → Token falsch oder widerrufen; neu bei @BotFather holen.
  • „400 Bad Request / chat not found" → Bot ist nicht im Ziel-Chat Mitglied bzw. ID-Tipp (Vorzeichen beachten).
  • „429 Too Many Requests" → Telegram-Rate-Limit; kurze Pause, dann erneut senden.
